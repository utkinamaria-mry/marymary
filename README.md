# Тренажёр: гражданство Грузии

Тренажёр для экзамена на гражданство Грузии по трём предметам: грузинский язык, история Грузии и основы права. В нём все 600 официальных вопросов SDA за 2024 год (sda.gov.ge), у каждого вопроса и варианта ответа есть перевод на русский.

Как открыть: откройте `index.html` в браузере. Прогресс хранится в браузере; его можно выгрузить в файл и загрузить обратно в «Настройках».

- `pdf/` — исходные PDF с sda.gov.ge
- `data/*.json` — вопросы, извлечённые из PDF (`tools/parse.py`)
- `data/ru/*.txt` — переводы на русский (`id|вопрос|вариант ## вариант ## …`)
- `tools/ru_txt2json.py` → `tools/build.py` собирают `questions.js`

Пересборка: `python3 tools/ru_txt2json.py && python3 tools/build.py`.
